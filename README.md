# JRE — Jornada, Realeza e Estratégia

Landing page desenvolvida para a **JRE**, marca de vestuário premium inspirada no universo do xadrez, na estratégia e na construção de autoridade.

## ✨ Sobre o projeto

A landing page apresenta a identidade e o propósito da JRE por meio de uma experiência sofisticada, imersiva e responsiva.

A narrativa acompanha a evolução do peão ao rei, conectando moda, estratégia, postura e propósito. O projeto também apresenta os lançamentos da marca e direciona o público para atendimento e Lista VIP pelo WhatsApp.

- TanStack Start

## ▶️ Executando o projeto

Você precisa ter o Node.js e o npm instalados.

Clone o repositório:

```bash
git clone <url-do-repositorio>
```

Entre na pasta do projeto:

```bash
cd <nome-do-projeto>
```

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

Abra no navegador o endereço exibido no terminal, geralmente:

```text
http://localhost:3000
```

## 📦 Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Antes de publicar, confirme que o processo foi concluído sem erros.
